# Этап 3: Проектирование базы данных

## Цель этапа
Разработать логическую и физическую модель данных для серверной части мобильного приложения «План Дня», создать DDL-скрипты для PostgreSQL и определить стратегию объектно-реляционного отображения (ORM) с использованием JPA/Hibernate.

## Результаты
- ER-диаграмма логической модели данных
- DDL-скрипты для создания таблиц, индексов и ограничений
- Описание маппинга сущностей JPA
