# Руководство пользователя

## Мобильное приложение «Plan Day»

---

## 1. Начало работы

### 1.1 Установка

1. Получите файл `app-debug.apk` от разработчика или установите из Google Play.
2. На устройстве разрешите установку из неизвестных источников: **Настройки → Безопасность → Неизвестные источники**.
3. Откройте APK-файл и нажмите **Установить**.

### 1.2 Первый запуск

При первом запуске отображается экран входа. Если у вас нет аккаунта — нажмите **Зарегистрироваться**.

---

## 2. Регистрация и вход

### 2.1 Регистрация

![Экран регистрации](<images/screen-register.png>)

1. Введите **логин** (3–50 символов, уникальный).
2. Введите **email** (действующий адрес, уникальный).
3. Введите **пароль** (минимум 6 символов).
4. Нажмите **Зарегистрироваться**.

После успешной регистрации вы автоматически войдёте в систему.

### 2.2 Вход

1. Введите **email** и **пароль**.
2. Нажмите **Войти**.

---

## 3. Работа с папками

### 3.1 Главный экран

![Список папок](<images/screen-folders.png>)

На главном экране отображается список всех ваших папок. Каждая папка показывает своё название с цветовой меткой.

- **Нажать на папку** — открыть список задач
- **Кнопка «корзина»** на карточке — удалить папку

> ⚠️ При удалении папки безвозвратно удаляются все её задачи.

### 3.2 Создание папки

1. Нажмите кнопку **+** (FAB) в правом нижнем углу.
2. Введите **название** папки.
3. Выберите **цвет** (синий, зелёный, оранжевый или фиолетовый).
4. Нажмите **Сохранить**.

---

## 4. Работа с задачами

### 4.1 Список задач

![Список задач](<images/screen-tasks.png>)

После открытия папки вы видите список её задач.

- **Чекбокс** слева от задачи — отметить как выполненную
- **Нажать на задачу** — открыть для редактирования
- **Кнопка «корзина»** — удалить задачу

### 4.2 Создание задачи

1. В списке задач нажмите **+** (FAB).
2. Заполните поля:
   - **Название** (обязательно)
   - **Описание** (необязательно)
   - **Дата** — нажмите на поле для выбора даты
   - **Время** — нажмите на поле для выбора времени
3. При необходимости добавьте **подзадачи** кнопкой «Добавить подзадачу».
4. Нажмите **Сохранить**.

### 4.3 Редактирование задачи

Нажмите на задачу в списке — откроется экран редактирования с теми же полями. Внесите изменения и нажмите **Сохранить**.

Кнопка **Закрыть** — закрывает экран без сохранения изменений.

---

## 5. Профиль пользователя

![Профиль](<images/screen-profile.png>)

Для перехода в профиль нажмите **⋮** (меню) → **Профиль**.

В профиле отображается:
- Полное имя
- Логин
- Email
- Дата регистрации
- Количество задач

### Изменение имени

1. Нажмите на поле **Полное имя**.
2. Введите новое имя.
3. Нажмите **Сохранить**.

---

## 6. Работа без интернета

Приложение работает в **оффлайн-режиме**: все данные хранятся локально на устройстве.

- Создание, редактирование и удаление папок/задач доступно без интернета.
- При восстановлении соединения данные автоматически синхронизируются с сервером.

---

## 7. Выход из аккаунта

Нажмите **⋮** (меню) → **Выйти**.

---

## 8. Системные требования

| Параметр | Требование |
|---|---|
| Android версия | 8.0 (API 26) и выше |
| Свободная память | 50 МБ |
| Интернет | Необходим для входа и синхронизации |
