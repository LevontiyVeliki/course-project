## Описание сущностей

### Пользователь (User)

**Атрибуты:** логин, email, пароль (хранится в хешированном виде), полное имя, роль, дата регистрации.

**Правила:**
- Логин и email должны быть уникальными в системе.
- Пароль должен содержать не менее 6 символов.
- Роль по умолчанию — `USER`.

---

### Папка / Список дел (TaskList)

**Атрибуты:** название, дата исполнения, статус, дата создания/изменения, цвет (для отображения в UI).

**Правила:**
- Название списка обязательно.
- Статус по умолчанию — `ACTIVE`.
- При удалении папки каскадно удаляются все вложенные задачи и напоминания.

---

### Задача (Task)

**Атрибуты:** название, описание, статус выполнения, дата/время исполнения, дата создания/изменения.

**Правила:**
- Название задачи обязательно.
- Статус по умолчанию — `PENDING` (Ожидает).
- Если дата исполнения задачи прошла и задача не выполнена, статус меняется на `OVERDUE`.

---

### Подзадача (Subtask)

**Атрибуты:** текст, статус выполнения, порядковый номер.

**Правила:**
- Текст подзадачи обязателен.
- Подзадача принадлежит ровно одной задаче.
- При удалении задачи каскадно удаляются все её подзадачи.

---

### Напоминание (Reminder)

**Атрибуты:** тип (список / задача), время срабатывания, сообщение, флаг отправки, дата создания.

**Правила:**
- Время срабатывания не может быть в прошлом (при создании).
- Один список или задача может иметь не более одного активного напоминания.
- Сообщение генерируется автоматически на основе названия, но может быть изменено пользователем.

---

## Связи между сущностями

| Связь | Мощность | Описание |
|---|---|---|
| Пользователь → Папка | 1 : N | Один пользователь владеет многими папками |
| Папка → Задача | 1 : N | Одна папка содержит много задач |
| Задача → Подзадача | 1 : N | Одна задача содержит много подзадач |
| Задача → Напоминание | 1 : 0..1 | На задачу можно установить одно напоминание |
