## Пользователь
Атрибуты: логин, email, пароль (хранится в хешированном виде), 
имя, роль, дата регистрации.
Правила:
-- Логин и email должны быть уникальными в системе.
-- Пароль должен содержать не менее 6 символов.
-- Роль по умолчанию — USER.

## СписокДел
Атрибуты: название, дата исполнения, статус, дата создания/изменения.
Правила:
-- Дата исполнения не может быть пустой.
-- Название списка обязательно.
-- Статус по умолчанию — АКТИВЕН.
-- При удалении списка каскадно удаляются все вложенные задачи и напоминания.

## Задача
Атрибуты: описание, статус, приоритет, порядковый номер 
(для сортировки в UI), дата создания/изменения.
Правила:
-- Описание задачи обязательно.
-- Статус по умолчанию — ОЖИДАЕТ.
-- Если дата исполнения родительского списка прошла, а задача не выполнена, статус автоматически меняется на ПРОСРОЧЕНА при запросе данных.
-- Приоритет по умолчанию — СРЕДНИЙ.

## Напоминание
Атрибуты: тип, время срабатывания, сообщение, флаг отправки, 
дата создания.
Правила:
-- Время срабатывания не может быть в прошлом (при создании).
-- Один список или задача может иметь не более одного активного напоминания.
-- Сообщение генерируется автоматически на основе названия списка/задачи, но может быть изменено пользователем.
