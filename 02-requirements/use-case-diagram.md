## Описание акторов

| Актор | Описание |
|---|---|
| **Пользователь** | Основной пользователь мобильного приложения, управляющий своими папками, задачами и подзадачами. |
| **Администратор** | Привилегированный пользователь, управляющий учётными записями других пользователей и системными настройками (доступ через отдельный интерфейс). |
| **Сервер push-уведомлений** | Внешняя система (Firebase Cloud Messaging), обеспечивающая доставку напоминаний на устройства пользователей. |

---

## Перечень прецедентов

| ID | Прецедент | Краткое описание |
|---|---|---|
| UC1 | Зарегистрироваться | Создание новой учётной записи в системе. |
| UC2 | Войти в систему | Аутентификация пользователя по логину/паролю, получение JWT-токена. |
| UC3 | Создать список дел | Создание нового контейнера задач, привязанного к конкретной дате. |
| UC4 | Редактировать список дел | Изменение названия списка или даты исполнения. |
| UC5 | Удалить список дел | Удаление списка вместе со всеми вложенными задачами. |
| UC6 | Добавить задачу в список | Создание новой задачи внутри выбранного списка. |
| UC7 | Отметить задачу выполненной | Изменение статуса задачи на «Выполнена». |
| UC8 | Установить напоминание | Настройка времени и сообщения для push-уведомления о задаче. |
| UC9 | Просмотреть список дел | Отображение всех папок и задач пользователя. |
| UC10 | Синхронизировать данные | Ручной или автоматический запуск обмена данными с сервером. |
| UC11 | Управлять пользователями | Просмотр, блокировка, удаление учётных записей (только администратор). |
