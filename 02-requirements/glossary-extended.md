| Термин 		| Определение 	|
| **Пользователь** 	| Зарегистрированное лицо, использующее мобильное приложение для управления личными списками дел. |
| **Список дел** 	| Контейнер задач, привязанный к конкретной дате исполнения. |
| **Задача** 		| Отдельное действие, которое необходимо выполнить в рамках списка дел. |
| **Напоминание** 	| Push-уведомление, отправляемое пользователю в заданное время для информирования о списке или задаче. |
| **Дата исполнения** 	| Календарная дата, к которой относится список дел. |
| **Статус списка** 	| Состояние списка: «Активен» (текущий или будущий), «Завершён» (все задачи выполнены или список помечен завершённым вручную). |
| **Статус задачи** 	| Состояние задачи: «Ожидает», «Выполнена», «Просрочена». |
| **Приоритет** 	| Степень важности задачи: «Низкий», «Средний», «Высокий». |
| **Синхронизация** 	| Процесс обмена данными между мобильным клиентом и сервером. |
| **Оффлайн-режим** 	| Возможность работы с приложением без подключения к сети, с сохранением изменений в локальной БД. |
| **JWT** 		| JSON Web Token — компактное средство представления утверждений (claims) для аутентификации и авторизации в REST API. |
| **BCrypt** 		| Алгоритм хеширования паролей, устойчивый к атакам перебором. |
| **REST API** 		| Архитектурный стиль взаимодействия компонентов распределённого приложения посредством HTTP-запросов. |
| **OpenAPI (Swagger)** | Спецификация для описания REST API, включающая интерактивную документацию. |
| **(FCM)** 		| Сервис Google для доставки push-уведомлений на устройства Android. |
| **Spring Boot** 	| Фреймворк для создания автономных приложений на Java с минимальной конфигурацией. |
| **PostgreSQL** 	| Объектно-реляционная система управления базами данных. |
| **PCMEF** 		| Архитектурный паттерн (Presentation-Control-Mediator-Entity-Foundation), адаптированный для клиент-серверных приложений. |
| **Модульное тестир.** | Тестирование отдельных компонентов программного кода (классов, методов) в изоляции от внешних зависимостей. |
| **JaCoCo** 		| Инструмент для измерения покрытия кода тестами в Java-проектах. |
| **Локальное кэшир.** 	| Хранение данных на устройстве пользователя (SQLite/Room) для обеспечения работы приложения без сети. |
| **DTO** 		| Data Transfer Object — объект, используемый для передачи данных между подсистемами (например, между клиентом и сервером). |
| **Entity** 		| Класс, представляющий строку таблицы базы данных в объектно-ориентированном программировании (JPA). |
| **Repository** 	| Паттерн, абстрагирующий доступ к хранилищу данных. |
| **Service** 		| Слой бизнес-логики в архитектуре Spring. |
| **Controller** 	| Компонент, обрабатывающий входящие HTTP-запросы в Spring MVC. |
| **CORS** 		| Cross-Origin Resource Sharing — механизм, разрешающий веб-страницам запрашивать ресурсы с другого домена. |
| **DDL** 		| Data Definition Language — подмножество SQL для определения структуры базы данных. |
| **WBS** 		| Work Breakdown Structure — иерархическая структура работ проекта. |
| **ADR** 		| Architecture Decision Record — документирование важных архитектурных решений. |
