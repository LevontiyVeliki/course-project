# Бизнес-глоссарий проекта «План Дня»

| Термин | Определение | Синонимы |
| **Список дел** | Контейнер, объединяющий одну или несколько задач и привязанный к конкретной календарной дате.| План на день, Task Group, Agenda |
| **Задача** | Отдельное действие, которое необходимо выполнить в рамках определенного Списка дел.| Task, To-Do, Поручение |
| **Напоминание** | Уведомление, отправляемое пользователю на мобильное устройство в заданное время с целью напомнить о Списке дел или конкретной Задаче. | Alert, Notification, Уведомление |
| **Пользователь** | Физическое лицо, использующее мобильное приложение для планирования собственных дел. | User, Аккаунт |
| **Дата исполнения** | Календарный день, к которому привязан Список дел. Задачи внутри списка не имеют собственных дат, наследуя её у родительского списка. | Scheduled Date, Target Day |
| **Статус задачи** | Состояние задачи: «Ожидает», «Выполнена», «Просрочена». | Task Status |
| **Просроченная задача** | Задача из Списка дел на прошедшую дату, которая не была отмечена как выполненная. | Overdue Task |
| **Синхронизация** | Процесс обмена данными между мобильным приложением и серверной частью для обеспечения актуальности данных на всех устройствах пользователя. | Sync |
| **Оффлайн-режим** | Возможность работы с приложением (просмотр, создание, редактирование задач) при отсутствии подключения к сети Интернет. Данные сохраняются локально до восстановления связи. | Offline Mode |
| **JWT токен** | JSON Web Token, используемый для безопасной аутентификации пользователя при запросах к серверному API без постоянной передачи логина и пароля. | Access Token, Bearer Token |
| **Роль** | Набор прав доступа в системе. Выделяются роли «Пользователь» (базовые права на свои списки) и «Администратор» (доступ ко всем данным и настройкам системы). | Role, Права доступа |
| **Архивация** | Автоматическое или ручное перемещение выполненных Списков дел за прошлые периоды в архив для оптимизации работы интерфейса. | Archive |
| **Повтор задачи** | Возможность автоматического копирования задачи в новый Список дел на будущую дату (ежедневно, еженедельно). (Примечание: относится к перспективному развитию системы). | Recurring Task |
| **Push-уведомление** | Технология отправки сообщений с сервера на мобильное устройство через сервисы Google (FCM) или Apple (APNs). | Push Notification |
| **Серверная часть** | Программный компонент (Spring Boot), обеспечивающий хранение данных, бизнес-логику и REST API для взаимодействия с мобильным клиентом. | Backend, Сервер |
| **Клиентская часть** | Мобильное приложение, установленное на устройстве пользователя (Android), отвечающее за отображение данных и взаимодействие с пользователем. | Frontend, Клиент |
| **Время создания** | Дата и время, когда запись (Список или Задача) была впервые сохранена в системе. | Created At |
| **Время последнего изменения** | Дата и время последнего обновления записи. | Updated At |
| **Фильтрация** | Возможность отображения списков задач за определенный период (неделя, месяц) или по статусу выполнения. | Filter |
| **Поиск** | Функция быстрого нахождения задачи по ключевым словам в названии или описании. | Search |
