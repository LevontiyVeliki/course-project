## 2. БИЗНЕС-КОНТЕКСТ

**Проблема:**
Существующие календари и планировщики ориентированы на фиксацию точечных событий (встреч) в привязке к жесткому времени. 
Пользователи испытывают трудности при планировании комплексных списков дел на день, когда важен не столько точный час, 
сколько сам факт выполнения набора задач в течение суток. 
Отсутствует удобный инструмент для группировки задач по дням с гибкой системой напоминаний, не перегружающий интерфейс событиями.

**Решение:**
Разработать мобильное приложение, позволяющее создавать «Списки дел» (контейнеры), привязанные к определенной дате. 
Внутри списка пользователь может добавлять неограниченное количество отдельных задач. 
Приложение предоставляет возможность установки общих напоминаний на список (утром в день исполнения)
и персональных напоминаний на конкретные задачи, обеспечивая фокус на выполнении, а не на планировании.

## 3. ЦЕЛИ ПРОЕКТА

1.  **Обеспечить удобное управление задачами:** Реализовать интуитивный мобильный интерфейс для создания, 
редактирования и удаления списков дел и вложенных в них задач.
2.  **Внедрить гибкую систему уведомлений:** Разработать серверную логику для отправки push-уведомлений
о предстоящих задачах и списках.
3.  **Обеспечить надежное хранение данных:** Создать серверную часть с REST API и базой данных 
для синхронизации данных между устройствами пользователя.

## 4. КЛЮЧЕВЫЕ ПОКАЗАТЕЛИ УСПЕХА

- **Время создания нового списка задач:** не более 30 секунд.
- **Количество экранов мобильного приложения:** не менее 5.
- **Стабильность API:** время ответа сервера (95-й перцентиль) менее 500 мс.
- **Покрытие кода серверной части тестами:** > 40%.

| Риск | Стратегия реагирования |
